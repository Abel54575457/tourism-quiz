# 觀光餐旅概論雲端闖關與檢測系統 (Tourism & Hospitality Quiz Game)

一套適用於全國技術型高中（高職）與綜合高中餐旅群學生的**無伺服器 (Serverless) 雲端學習、章節小考與全真模擬測驗系統**。

---

## 🌟 系統特色

1. **🏆 51 關卡完整題庫 (`questions.js`)**：
   * 包含 652 題統測歷屆試題與自編題，並由 AI 延伸補足至完整章節關卡（每關 20 題，滿分 100 分，85 分過關）。
   * 每章結尾設有**「章節總整理考試」**，從該章題目微調變形出題。
   * 課程最後設有 **5 回全真跨章節模擬測驗**。
   * 題庫內 **1,060 題全部附帶詳細的考點解析與錯誤說明**。

2. **🔐 學生自填式帳密登入與分區選校 (`index.html`)**：
   * 首次登入即自動完成註冊。
   * 整合全台高中職餐旅群學校清單，採「北區、中區、南區、東區及離島」雙層下拉選單，並支援手動輸入校名。
   * 實時計算全國總積分榮譽榜，並可切換「校內排行」。

3. **🎮 遊戲端與錯題解析 (`game.html`)**：
   * 支援「閱讀認字」與「聽音辨字」雙模式。
   * 測驗結束後即時顯示**錯題複習卡**（標註學生答案、正確答案與詳細解析）。
   * 配備**「問題回報」**按鈕，方便學生一鍵通報題目疑義。

4. **📊 教師/管理員監控後台 (`admin.html`)**：
   * 預設管理密碼：`116`
   * 即時監控全國學生進度，並支援一鍵匯出全體成績為 **Excel (.xlsx)** 表格。
   * 設有**「問題回報審查區」**，方便管理員隨時檢視並刪除已處理的回報。

